# AI-оркестратор (админка → «ИИ-студия»)

Роли: **Groq** — черновики глав, правки по замечаниям, аннотация. **Gemini** — план и «библия» книги, редактор каждой главы, извлечение фактов и кратких содержаний, итоговая проверка. **OpenRouter** — одна явно выбранная экспертная модель: правка главы, не прошедшей проверки, и вторая оценка книги. **Сервер** — версии, задания, лимиты, программные проверки, журнал, публикация только после подтверждения.

Порядок: план → ваше утверждение → для каждой главы: черновик (Groq) → программная проверка → редактор (Gemini) → при замечаниях до N кругов правок (Groq) → эксперт (OpenRouter, один раз) → ваше решение, если не вышло → факты и краткое содержание (Gemini) → следующая глава → итоговая проверка → аннотация → ваше подтверждение публикации.

## Переменные окружения (секреты и vars Worker)
| Переменная | Значение |
|---|---|
| `GROQ_API_KEY`, `GEMINI_API_KEY`, `OPENROUTER_API_KEY` | ключи (или добавьте их в «ИИ: быстро» → Ключи) |
| `AI_DRAFT_MODEL`, `AI_EDITOR_MODEL`, `AI_EXPERT_MODEL` | id моделей Groq, Gemini и OpenRouter. **Моделей по умолчанию нет.** Эксперт необязателен |
| `AI_DRAFT_FALLBACK`, `AI_EDITOR_FALLBACK`, `AI_EXPERT_FALLBACK` | запасные провайдеры: `провайдер:модель,провайдер:модель` |
| `AI_PRICES` | JSON `{"groq:модель":[вход,выход]}` — цена за 1 млн токенов; для OpenRouter цены берутся из его списка моделей |
| `AI_MAX_JOBS` (2), `AI_MAX_CALLS` (80), `AI_MAX_TOKENS` (400000), `AI_MAX_COST_USD` (нет), `AI_FIX_ROUNDS` (2) | серверные пределы; админ может только уменьшить их для задания |

Модели проверяются при создании задания по живому списку самого сервиса (`/models`); неизвестная модель отклоняется. Стоимость считается только при известной цене, иначе в журнале «цена неизвестна».

## Что хранится
`ai_jobs`, `ai_chapters`, `ai_versions` (черновик, исправления, правка эксперта, правка админа — ничего не перезаписывается), `ai_checks` (программные, редактор, итоговые), `ai_calls` (задача, провайдер, модель, задержка, токены, стоимость, результат, причина ошибки; `via=override` — вызов тестового стенда, а не настоящего сервиса).

## Возобновление
Каждый `POST /api/admin/ai/jobs/:id/step` делает один шаг и сохраняет результат. Блокировка не даёт двум шагам одного задания идти параллельно. Лимит вызовов, токенов или стоимости, сбой всех провайдеров или отсутствие ключа ставят задание на паузу с причиной; «Продолжить» идёт с того же места, успешные вызовы не повторяются.

## Что проверено
Юнит-тесты (`tests/orch.test.js`) и интеграционные (`tests/e2e/orch.mjs`, `orch-ui.cjs`) на **имитации провайдеров** (`tests/e2e/ai-mock.mjs`). Настоящие Groq, Gemini и OpenRouter в этой среде не вызывались: нет ключей и доступа к их доменам.
