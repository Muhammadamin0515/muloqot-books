# Muloqot Books: аудит, план и результаты (каталог, читалка, права, аудио)

Ветка: `claude/trusting-albattani-kaixsz`. `main` не менялся, деплоя и изменений production не было.

## 2. План и что сделано

1. **Отделение тестовых данных** (`worker/schema.js`): метка `demo` у книг, авторов, отзывов, тем и цитат; ничего не удалено. Режим «Авто/Показывать/Скрыть» в Админ → Каталог. В режиме «Авто» тестовые данные видны только пока в каталоге нет настоящих книг.
2. **Права** (`worker/catalog.js`): основания `public_domain / permission / licensed / author / unverified`. Полный текст отдаётся только при подтверждённом основании; для общественного достояния нужен год смерти автора не позже (текущий − 71, срок «жизнь + 70 лет» по законодательству Узбекистана); для остальных нужна https-ссылка или описание документа. Отзыв подтверждения скрывает текст сразу. Все действия пишутся в `audit_log`. Книги, опубликованные до появления учёта прав, остаются доступны и помечены «ПРОВЕРИТЬ».
3. **Импорт** (Админ → Каталог): одна книга (файл EPUB/DOCX/PDF/TXT/MD или только карточка) и пакетный JSON; обязательные источник и права; обложка файлом или ссылкой с разрешённых хостов (Open Library, Wikimedia, Gutenberg; остальные не загружаются). `data/catalog.classics.json`: 27 карточек произведений общественного достояния (русская и узбекская классика) **без текста**; `scripts/enrich-catalog.mjs` подтягивает тексты Gutenberg и обложки Open Library (нужен интернет).
4. **EPUB** (`src/epub.js`, `src/zip.js`): метаданные, оглавление, главы; EPUB с DRM отклоняется. Работает в студии автора и в админ-импорте.
5. **Рейтинги и популярность**: рейтинг только по реальным оценкам, распределение считается из таблицы оценок, у книги без оценок написано «Оценок пока нет»; популярность (`pop`) = чтения, дочитывания, просмотры за 30 дней и число оценок.
6. **Поиск** (`src/search.js`): совпадение кириллицы и латиницы (Навоий = Navoiy), опечатки (расстояние Дамерау-Левенштейна), русские окончания, подсказка «Искать: …», фильтры по языку, жанру, «читать целиком», «аудио», сортировки.
7. **Главная**: блок «Для вас» (`src/reco.js`: жанры, авторы, язык, оценки, подписки, пояснение «Похоже на …»; без сигнала не показывается), «Популярное» только при реальной активности, пустые разделы скрыты.
8. **Карточка книги**: серия, оригинальное название, переводчик, издатель, ISBN, формат (текст/аудио/только описание), доступность полного текста, права и источник. Для книги без прав кнопки «Читать» нет, вместо неё честное объяснение.
9. **Читалка**: позиция хранится по абзацам и переживает смену шрифта; при входе слияние прогресса по книгам (новее побеждает), списки объединяются, офлайн-чтение не теряется; «Вопрос недели» создаёт обычную тему.
10. **Аудио** (`src/audio.js`, таблица `audio_tracks`): настоящий плеер на `<audio>`, скорость 0.75–2×, ±15/30 с, треки, Media Session, позиция и скорость сохраняются и синхронизируются. Файлы добавляет админ ссылками https и только для книг с подтверждёнными правами; без треков плеера нет. Загрузку самих аудиофайлов в хранилище (R2) не делал.
11. **Безопасность**: `x-dev-user` работает только на `localhost`; CSP, `nosniff`, Referrer/Permissions-Policy через `public/_headers`; лимит тела запроса; лимит 8 заявок в сутки; проверки владельца для заявок и книг; тест на то, что все 47 админ-маршрутов закрыты для обычного читателя.
12. **Тесты**: 28 модульных (`npm test`) и 79 сценариев на живом сервере и в браузере (`npm run e2e`).

## 3. Не сделано / ограничения

- **Реальные данные не загружены**: из среды разработки внешние источники (Gutenberg, Open Library, Wikisource, Wikidata) недоступны (политика сети, 403). Загрузка выполнена как безопасная интеграция: запустите `node scripts/enrich-catalog.mjs` у себя и импортируйте результат из админки. Скрипт в этой среде не выполнялся до конца.
- Описания в `catalog.classics.json` и годы написаны по справочным знаниям редакции, помечены источником «проверить по первоисточнику» и не заменяют проверку. Права на конкретные издания и переводы не подтверждены, поэтому текст не включён.
- Книги длиннее 1,4 МБ чистого текста (например «Война и мир») нужно делить на тома: ограничение строки D1 (2 МБ).
- Современные переводы и книги правообладателей публикуются только при наличии разрешения или лицензии (основания `permission` / `licensed` с доказательством).
- Аудио: нет загрузки файлов в Worker/R2, нет «продолжить прослушивание» на главной, нет таймера сна.
- Офлайн-режим клиента по-прежнему показывает встроенные тестовые данные (они в `src/data.js`); при подключении к серверу заменяются каталогом.
- Дизайн: приведены в порядок состояния «нет оценок / нет текста / пустой каталог», карточки, фильтры, плеер, админ-раздел. Полный редизайн и реальные обложки издательств не делались (обложки: загрузка автором/админом, ссылка из разрешённых хостов, либо автообложка).
- Деплой на Cloudflare и применение к production не выполнялись; схема обновляется сама при первом запросе (`ensureSchema`).

## 4. Запуск и проверка

```bash
npm install
npm test            # модульные тесты (поиск, EPUB, права, рекомендации, разбор глав)
npm run e2e         # сборка + чистая локальная D1 + API-сценарии + браузерные сценарии
npm start           # локальный сервер (wrangler dev)
```

Если `npm run e2e` запускается внутри инструмента, который убивает дочерние процессы (код 144), запустите `bash scripts/e2e.sh` в фоне и прочитайте вывод.

Перед выкладкой: проверьте в Админ → Каталог список «Проверить права» (старые книги), заполните начальный каталог (вставьте `data/catalog.classics.json` или результат `enrich-catalog` в «Пакетный импорт»), выберите режим тестовых данных.
