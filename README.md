# Muloqot Books — Telegram Mini App

Литературная платформа (RU/UZ): каталог, читалка, библиотека, сообщество, студия автора (демо).

## Локальный запуск
```
npm install
npm run db:migrate:local   # создать локальную D1 и засеять каталог
npm run start              # сборка + wrangler dev на http://localhost:8787
```
Без `BOT_TOKEN` включён dev-режим: пользователь задаётся заголовком `x-dev-user` (в браузере `?as=admin` — администратор). Для разработки фронта: `npm run server` и `npm run dev` в двух терминалах (Vite проксирует `/api` на :3000, укажите `wrangler dev --port 3000`).

## Что реализовано
- Авторизация через Telegram `initData` (HMAC-проверка на сервере).
- Cloudflare D1 (SQLite): книги, авторы, отзывы и ответы, реакции, обсуждения и комментарии, цитаты сообщества, оценки (средний рейтинг считается из реальных оценок), подписки на авторов.
- Личное состояние (прогресс чтения, закладки, библиотека, настройки, серия дней) синхронизируется между устройствами.
- Студия автора (Профиль → Студия автора): мастер из 4 шагов — рукопись (.docx, .pdf, .txt, .md; PDF читается в браузере, номера страниц и колонтитулы убираются, главы определяются сами, показывается разбор и подсказки), описание, обложка (любое фото сжимается в браузере до ~200 КБ, либо одна из 8 автообложек), проверка и подтверждение прав. Черновик сохраняется на устройстве. Заявку можно отозвать, отклонённую — исправить и отправить заново. Админ публикует или отклоняет, книга сразу появляется в каталоге.
- Достижения (Профиль → Достижения): 15 для читателя и 9 для автора, считаются на сервере, о новом приходит уведомление в приложении.
- Бот (webhook): `/start` с кнопкой открытия, уведомления (ответ на отзыв/комментарий, новая книга автора, решение по заявке, напоминание о чтении в 19:00 по Ташкенту).
- Без сервера (статический хостинг) приложение работает локально, как раньше.

## Бот
Команды (RU/UZ по языку Telegram): `/start` приветствие, `/library`, `/donate`, `/support`, `/help`; кнопка меню «Читать». Любое обычное сообщение боту попадает в чат поддержки админ-панели, ответ админа приходит в бота. Приветствие (RU/UZ) и ссылка на мини-апп для «Поделиться» (формат `https://t.me/бот/имя_приложения`) настраиваются в Админ-панели → Контент → Бот. После деплоя один раз нажмите Админ-панель → Донаты → «Обновить настройки бота», чтобы применить команды и меню.
Глубокие ссылки: `…?startapp=book_<id>` открывает книгу; кнопки бота ведут в библиотеку, донаты и т. д.

## Рост и авторы
- Inline-поиск: в любом чате `@имя_бота запрос` показывает книги (без запроса популярные) и отправляет карточку со ссылкой «Читать в приложении». Включите в @BotFather: `/setinline` → выбрать бота → подсказка, например «Название книги или автор». Ссылка на мини-апп должна быть задана (Админ-панель → Контент → Бот).
- Статистика автора (Профиль → Студия автора → «Мои книги»): просмотры, начали читать, дочитали, оценка, отзывы, график за 14 дней; правка названия и аннотации своей книги. У админа в обзоре популярные книги недели.
- Замена текста через модерацию: автор в «Мои книги» нажимает «Заменить текст», загружает новый файл и описывает изменения. Админ видит сравнение (главы, объём, начало текста) в Модерации и одобряет или отклоняет с причиной. До одобрения читатели видят прежнюю версию; оценки, отзывы и закладки сохраняются, место чтения подстраивается, если глав стало меньше. Пять последних версий текста хранятся, откат: Админ-панель → Контент → книга → «История текста».
- Загрузка рукописей: `.txt`, `.md`, `.docx` (заголовки Word «Заголовок 1» становятся главами).

## Порядок и уведомления
- Жалобы: у каждого отзыва, темы и комментария есть значок флага. Три жалобы скрывают контент автоматически, админ решает в Админ-панели → Жалобы (оставить, удалить, удалить и заблокировать автора). Там же стоп-слова.
- Защита от спама: не более 6 сообщений в минуту и 60 в час, ссылки и повторы запрещены (админы исключены).
- Бот: `/notifications` (кнопки включения типов уведомлений), `/stop` (отключить всё).
- Напоминание о чтении приходит около 19:00 по Ташкенту, если человек сегодня не читал: «Вы остановились на «…», глава N» с кнопкой, открывающей чтение (cron каждые 5 минут в окне 19:00 to 20:55, по 18 человек за запуск).

## Производительность
Список книг при запуске содержит только названия и главы без текста; текст главы подгружается при открытии страницы книги (`/api/books/:id/text`), обложки опубликованных книг отдаются картинками (`/api/cover/:id`, кешируются браузером).

## Админ-панель (Профиль → Админ-панель)
Видна администраторам: ID из переменной `ADMIN_IDS` (главные, их нельзя снять) и админы, которых они добавили в панели.
- **Обзор:** пользователи (всего, новые, активные), доступные боту, книги, отзывы, график регистраций.
- **Рассылка:** тест себе или всем через бота, прогресс, история. Получают те, кто запускал бота и не блокировал его.
- **Модерация:** заявки на книги, предпросмотр текста, публикация или отклонение с причиной.
- **Чат:** переписка с пользователями (у них в профиле «Поддержка»), ответы дублируются в бота.
- **Люди:** поиск, блокировка, назначение и снятие админов, добавление админа по ID.
- **Контент:** вопрос недели, подборки, скрытие/удаление/правка книг. Отзывы и обсуждения админ удаляет значком корзины в «Сообществе».
Таблицы для панели создаются автоматически при первом запросе, ручных миграций не нужно.

## Донаты (Telegram Stars)
Экран «Поддержать проект» (кнопка в профиле, баннер на главной, кнопка в конце книги): суммы-подсказки и своя сумма, цели сбора с прогрессом, сообщение и анонимность, стена меценатов, значок ⭐ у мецената в отзывах. Оплата через Telegram Stars: договор и платёжный аккаунт не нужны, вывод через Fragment в TON.
Админ-панель → **Донаты**: итоги, кнопка «Подключить платежи» (ставит webhook бота сама), цели сбора, тексты и суммы, ссылки на другие способы (Click, Payme и т. д.), ручное добавление переводов, возвраты.
Для приёма платежей нужен секрет `BOT_TOKEN`; webhook-секрет вычисляется из токена, `WEBHOOK_SECRET` не обязателен.

## Деплой на Cloudflare (Workers + D1 + статика)
1. `npx wrangler login`
2. `npx wrangler d1 create muloqot-books` и вставьте выданный `database_id` в `wrangler.jsonc`.
3. `npm run db:migrate` — схема и стартовый каталог в боевую D1.
4. В панели Cloudflare → Settings → Variables and Secrets (тип Text; в `wrangler.jsonc` включён `keep_vars`, значения не затираются деплоем): `ADMIN_IDS` (ваш Telegram ID, через запятую) и `WEBAPP_URL` (адрес воркера, появится после первого деплоя).
5. Секреты: `npx wrangler secret put BOT_TOKEN` (токен из @BotFather) и `npx wrangler secret put WEBHOOK_SECRET` (любая случайная строка).
6. `npm run deploy` — получите адрес `https://muloqot-books.<аккаунт>.workers.dev`. Впишите его в `WEBAPP_URL` и задеплойте ещё раз.
7. Вебхук бота:
```
curl "https://api.telegram.org/bot<BOT_TOKEN>/setWebhook" \
  -d url=https://<адрес-воркера>/telegram/webhook -d secret_token=<WEBHOOK_SECRET>
```
8. В @BotFather: `/newapp` (или `/setmenubutton`) с адресом воркера.

Автодеплой из GitHub: в Cloudflare → Workers & Pages → Create → Import repository; build command `npm run build`, deploy command `npx wrangler deploy`.
Напоминания о чтении работают по Cron Trigger (`0 14 * * *` UTC = 19:00 Ташкент).

## Структура
`worker/` API Worker (D1, бот, cron) · `migrations/` схема и сид (сид генерируется `npm run gen-seed` из `src/data.js`) · `src/` фронтенд (`app.js`, `api.js`, `telegram.js`, `data.js`, `i18n.js`, `art.js`).


## Настоящий каталог, права, EPUB, аудио
Подробности, аудит и список ограничений: [docs/AUDIT.md](docs/AUDIT.md).
- Админ → **Каталог**: импорт книг (EPUB, DOCX, PDF, TXT, MD или только карточка; пакетный JSON), подтверждение прав, добавление текста и аудио, переключатель тестовых данных, журнал действий.
- Полный текст виден читателям только при подтверждённых правах (общественное достояние по году смерти автора, разрешение, лицензия, автор). Без прав книга остаётся карточкой.
- Тестовые данные помечены и скрываются, когда в каталоге появляются настоящие книги.
- Тесты: `npm test` и `npm run e2e`.
